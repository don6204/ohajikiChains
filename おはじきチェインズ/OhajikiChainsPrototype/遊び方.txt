操作
・起動時はタイトル画面。画面をタップ / クリックするとホームへ進みます。
  左上の「バックアップ連携」で連携画面を開き、「閉じる」でタイトルへ戻ります。
  Apple ID / Google連携は仕様どおり準備中で押せません。
  右上の「X」は指定アカウントをブラウザーで開きます。
・ホームで左右矢印からマイデッキを選び「バトルへ」で開始。
・フッター「スピリター」からデッキ編成と強化。編成は12体選び、確認の「決定」で保存。
・強化はキャラ→素材→個数→確認。「戻る」でキャンセル可能。
・フッター「ガチャ」から恒常/イベント/限定/有償の4種類→1連または10連。レアリティ別排出率も表示。
  全24種中、初期所持12種。★1〜★5の仮キャラを入手可能。重複は所持数として保持。
  初回1連は全ガチャ共通で宝石1個、通常1連は5個、10連は50個でおまけ宝石1個。
  有償枠も共通の宝石で試作。宝石はショップの仮購入・交換から入手できます。
  目玉キャラは約5秒で切り替わり、左右の矢印でも変更できます。
  3Dの召喚遺跡→ボール落下→解放→全身キャラ登場の順で演出します。
  右上スキップ：単発はキャラ登場へ、10連は結果一覧へ。つぎへで続けます。
  消費と獲得は確認時に確定し、演出のスキップや中断で重複しません。
・「ショップ」で交換/購入を切替。確認の「はい」で消費・付与、「いいえ」で取消。
  購入は仮処理で、実際の請求や決済画面への移動はありません。
  記念パックは各1000円表示、対応属性パワー20個＋宝石10個（仮内容）。
  宝石購入は1/32/80/180個。交換はメダル、パワー、輝く石→宝石。
  イベント交換所は非開催中ロック。設定画面は準備中Buttonのみ。
・プレミアムは800円表示、毎日宝石2個。その月の月末まで有効で自動更新しません。
  今回は購入当日も付与。購入履歴・日次受取履歴は終了時にリセットされます。
・下の4枚からキャラを選択。長押しするとスキルとステータスの詳細を表示。
  離す、カードの外に移動する、ウィンドウを切り替えると閉じる。
・盤面下部をクリックして発射位置を調整。
・発射ボールを押して、飛ばす方向（上方向）へドラッグして離す。
・右上のダメージ加算UIは、味方・敵のショット開始から攻撃演出終了まで表示。
  発射前、敵の待機中、次ターン待機、結果、再挑戦直後は非表示です。
  ダメージが増えると背景が黄色→オレンジ→淡いコーラルへ連続的に変わります。
  仮の目安は0 / 300 / 600ダメージ。600以上は色を維持し、真っ赤にはしません。
  数字の白〜クリーム色と金色の縁は残し、新しいショットごとに黄色へ戻ります。
・接触のたびに二重の輪・星・加算数字が広がり、光が右上へ飛ぶ。
  右上の大きな通常ダメージは位置・角度・縦横のサイズが震え、数字が大きく跳ねる。
  同属性への接触とスキルLv上昇では演出が強くなり、連鎖の節目にも表示が出る。
  SEはありません（音声生成・再生コードを除去）。
・停止後は「合計確定→右上から相手へ光弾→通常ダメージ→右からキャラ登場→スキル発動」の順に進む。
  右上は防御前の通常ダメージ。着弾数字は防御と残HPを反映した実際のHP減少量。
・敵も上部からランダム方向へショットする。敵の行動中は味方を操作できない。
・双方の攻撃後に盤面の全ボールをリセットする。
・「一時停止」でショット・演出・敵行動を停止/再開。「再挑戦」で戦闘を初期化。
・「ホーム」で帰還。結果の経験値とメダルはホームへ反映。
・入場/再挑戦はエネルギー1を消費。途中帰還でも返却なし。5回消費後は再起動でリセット。

更新ルール
通常攻撃 = キャラの攻撃力 × 全接触数 × 0.15（相性も適用）。
無属性のチャージも全接触数に含む。0個なら通常攻撃は0。
同属性1/3/5/10個でスキル効果Lv2/3/4/5。0個でもスキルLv1は発動。
スピリターは火・水・木のみ。無属性はチャージボール専用。
火→木→水→火が有利1.2倍、逆方向は0.8倍。
味方のHPは編成した12体のHP合計。敵HPも仮の敵デッキの合計。
敵を先に倒すと敵のショットは始まらない。味方HP0で敗北。

データの調整（Unity Inspector）
Assets/Ohajiki/ShopConfig.asset：
  Products：商品ID、価格、付与内容、期間、購入上限、制限周期、オススメ/割引フラグ。
  日付：日本時間yyyy-MM-dd。終了日は0時から対象外。空欄は期間制限なし。
  Event Active / Event From / Event Until：イベント交換所の開催。
  Premium Daily Gems：パスの日次付与量。
Assets/Ohajiki/HubConfig.asset：
  Catalog：所持対象のキャラ一覧。Starting Owned Count：初期所持数。
  Deck Slots：マイデッキ枠。Starting Coins/Gems/Materials：初期資源。
  Maximum Energy / Battle Energy Cost：エネルギー。
  Max Spirit Level / Upgrade Coin Unit：強化上限とメダル単価。
  Banners：表示内容、目玉キャラ、抽選候補のインデックスと重み。
  Rarity Weights：★1〜★5の排出率（合計100）。まずレアリティ、次に該当キャラの重みで抽選。
  Available From/Until：ガチャの開催期間。現在は期間未設定の試作開放。
  Featured Indices：複数の目玉キャラ。Featured Cycle Seconds：自動切替間隔。
  First Single Gems / Single Gems / Ten Gems / Ten Bonus Gems：消費数とおまけ。
Assets/Ohajiki/BattleTuning.asset：
  Damage Color Full At：加算UIが上限のコーラル色になるダメージ（仮600）。
  Player Deck / Enemy Deck：各12体の参照。サイズ12を維持する。
  Effect Thresholds / Contact Attack Factor / Advantage / Disadvantage：戦闘ルール。
  Deceleration / Shot Radius / Maximum Shot Seconds：動き。
  Square Hitboxes：四角形の当たり判定（オンが更新仕様）。Radiusは半辺長。
  Board Columns / Board Rows / Element Weights：盤面と属性比率。
  Enemy Think Seconds / Enemy Minimum Angle：敵AI。
  Charge / Damage Flight / Normal Impact / Cut In / Impact Seconds：確定→光弾→通常→スライド→スキルの時間。
  Contact Effect Intensity / Seconds：接触演出の強度と寿命。
  Damage Number Punch / Counter Speed：累計数字の拡大と加算速度。
  Damage Bank Shake / Tilt：右上の加算UIの位置・角度の揺れ。
  Trail Opacity / Hit Shake：残像と画面振動。
  詳細：Docs/2026-11-09_演出ガチャ更新設計.txt
  Effect Max Diameter：停止時エネルギーの広がり。
  Long Press Seconds：長押し時間。
  Reward Experience / Reward Coins / Reward On Defeat：報酬。
  Max Rank / Rank Two Experience / Rank Bands：ランク表。
Assets/Ohajiki/Data/Spirits/*.asset：味方キャラのHP・攻撃・速度・成長・スキル。
Assets/Ohajiki/Data/Enemies/*.asset：敵の仮データ。味方とは独立。
Skill Powerの各要素が効果Lv1,2,3…に対応。割合系は0.1=10%。
Guard Turnsは相手の攻撃を受ける回数。再付与時は上書き。
データ変更はPlayを止めてから行い、再度Playで確認する。

再ビルド
PrototypeBuilder.Build：既存シーンを開いて設定を更新し、Windows-v7.1に出力。
既存のキャラアセット・デッキ設定は再ビルドで初期化されない。
編成に空欄があるとエラーで停止するため、12枠の参照を設定してからビルドする。
Minimum Swipe / Minimum Forward Swipe はプレイヤー入力専用で、敵の発射条件には影響しない。
Unityで別のシーンを編集中の場合は先に保存すること。
配布時にはexeだけでなくWindows-v7.1フォルダー全体を渡す（DoNotShip、Smokeは検証用）。
