開発者向け：旧4列形式の取り込み
DataInputImporterには 対象 / ID / 項目 / 値（英語 target / id / field / value）の簡易形式が残っています。
quest / spirit / enemy / battle / hub / shop の既存フィールドを検証して一括適用する方式です。
空欄は変更なし、0は値0。数式や不明なID/フィールド、範囲外の値は適用前に拒否します。
旧4列形式または空ブックのときだけビルド前に使用します。不正な簡易入力はビルドを止めます。
18シートの新マスターとは互換性がなく、手動メニューもその旨を表示して適用を拒否します。
新マスターをこの簡易形式に作り替える必要はありません。新マスターを正本として保持してください。
