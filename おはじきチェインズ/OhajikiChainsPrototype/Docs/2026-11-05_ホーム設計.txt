おはじきチェインズ：ホーム・編成・強化・無料ガチャの仮設計
更新日：2026-11-05

対象
仕様書「【おはじきチェインズ】仕様書.xlsx」のホーム以降を既存バトルへ接続する。
ユーザー回答により、ガチャは動作確認用の無料抽選まで実装する。
ショップ・設定は準備中のButtonのみ。仕様書原本は変更しない。

仕様との対応
・A117〜N128、描画内ヘッダー/フッター：ランク、メダル、宝石、エネルギー、現在デッキ、左右切替。
・A141〜M143：スピリター画面からデッキ編成、スピリター強化へ移動。
・B158〜M169：所持キャラの属性/レアリティ絞り込みと名前/属性/レアリティ順。
・C172〜C174、描画内の確認ダイアログ：12体選択して確認後に編成確定。
・B198〜M220：キャラ選択、アイテム選択、確認、強化後はキャラ詳細へ戻る。
・A238〜C245：目玉キャラ付きガチャバナーを縦スクロール表示。
・J45/J47/C59〜C61：メダルと属性別/全属性のスピリットパワーによる育成。
・J50：バトル参加時のエネルギー消費。

画面の流れ
起動 → ホーム
  ホーム ⇄ スピリター ⇄ ガチャ（共通フッター）
  ホーム → バトル → 結果 → ホーム または 再挑戦
  スピリター → デッキ編成 → 確認 → スピリター
  スピリター → 強化対象選択 → キャラ詳細 → 素材・個数選択 → 確認 → キャラ詳細
  ガチャ → バナー詳細 → 無料抽選 → 結果 → 再抽選 または 詳細
  ショップ/設定：押せない準備中Button。

実装の分担
・HubConfig：ホーム初期値、キャラ一覧、ガチャバナー、抽選候補と重み、強化上限/単価。
・PlayerSession：所持数、キャラレベル、素材、3デッキ、通貨/ランク、エネルギーを一元管理。
・HubView/HubWidgets：uGUIの画面、確認ダイアログ、スクロール一覧。
・PrototypeApp：ホームとバトルの切替。表示中のEventSystemは1つだけ。
・BattleLoadout：選択デッキと育成結果を複製し、既存のBattleTuningへ渡す。
・PrototypeBattle：従来のバトル処理。ホームと共有したPlayerProgressへ結果報酬を反映。

データを守るルール
・編集中の選択は一時データ。確認の「決定」を押すまで保存しない。
・編集中に別画面へ移る場合は、変更破棄の確認を挟む。
・12体未満、同じキャラの二重選択、未所持キャラの編成は拒否。
・強化は素材属性、素材数、メダル、上限を確認してまとめて反映。キャンセルでは消費しない。
・キャラの元ScriptableObjectは直接育成しない。バトル中のレベルは入場時点の複製。
・再ビルドは既存キャラ/敵/HubConfigの編集済み設定を上書きしない。
・バトルへ入る時（再挑戦も含む）にエネルギーを消費。途中帰還では返却しない。

現時点の仮置き（正式仕様ではない）
・キャラ一覧18種。初期所持12種。追加6種は既存イラストを共用した仮キャラ。
・マイデッキ3枠、各12種。重複獲得分は所持数として保持し、同一キャラを複数枠には入れない。
・初期メダル5000、宝石0、エネルギー5、火/水/木/全パワー各20。
・エネルギー消費1。自然回復、ランクアップ回復、回復アイテムは未実装。
・素材1個でレベル+1、上限50。費用は各レベルアップの「現在Lv×50」メダルの合計。
  例：Lv1→Lv4には素材3個、50+100+150=300メダル。
・バトル経験値は現行どおりプレイヤーランクへ反映。キャラ経験値の配分・必要経験値表は未確定のため未実装。
・火/水/木/全属性の4バナー。属性バナーは該当する6種、全属性バナーは18種から抽選。
・初期抽選重みはすべて1（属性別は各1/6、全属性は各1/18）。レアリティによる補正なし。
・Inspectorで候補と重みを変更可能。表示率は同じデータから計算する。
・無料単発のみ。宝石消費、課金、10連、天井、重複交換、演出の確定仕様は未実装。
・所持キャラ・育成・通貨・デッキは起動中のみ保持。終了時に保存しない。
・デザインは導線確認用。最終アート、アイコン、ガチャ演出、音、端末別調整は後工程。

調整場所
Unity Inspectorで Assets/Ohajiki/HubConfig.asset を選択する。
キャラ個別の能力・成長・レアリティは Assets/Ohajiki/Data/Spirits/ 以下。
バトルの既存数値は Assets/Ohajiki/BattleTuning.asset。
起動シーンは Assets/Ohajiki/Scenes/Prototype.unity。Playでホームから開始。

検証
EditModeテスト：所持/編成/絞り込み/無料抽選/強化消費/上限/複製/エネルギーと既存バトル。
明示的な --hub-smoke-test：画面遷移、確認のキャンセル/確定、スクロール、実バトルへの受渡しと報酬帰還。
報酬確認ではテスト専用に敵HPを1へ減らし、通常ショット解決から結果・報酬まで通す。
--stay-open 併用で検証終了後の画面を維持。通常起動ではテスト処理は動かない。
最新の検証結果と制限は同日のホーム検証結果ファイルに記録する。
